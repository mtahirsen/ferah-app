# Ferah — tanıtım sayfası

[Ferah](https://mtahirsen.github.io/ferah-site/) macOS için yerel bir disk bakım uygulaması: gereksiz dosya temizliği,
görsel disk haritası (Alan Merceği), geliştirici alanı ve menü çubuğu disk bekçisi.

Bu repo yalnızca tanıtım sayfasını içerir (tek dosya `index.html` + `assets/`). Ekran görüntüleri uygulamanın demo
modundan, sahte verilerle alınmıştır.
